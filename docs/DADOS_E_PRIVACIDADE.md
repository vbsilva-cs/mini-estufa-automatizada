# Dados e privacidade

## Natureza dos dados

- O sistema usa dataset simulado em `data/simulated/leituras.json`.
- Os dados são fictícios, determinísticos e reproduzíveis.
- Não há ingestão de dados pessoais no MVP.

## Armazenamento

- Limites são mantidos apenas em memória durante execução.
- Não há persistência histórica em banco no MVP.

## Privacidade e segurança

- Sem autenticação/autorização no protótipo.
- Sem integração com canais externos de notificação.
- O protótipo não deve ser tratado como ambiente de produção.
